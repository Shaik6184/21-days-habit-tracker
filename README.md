# 🗓️ 21 Days Habit Tracker

**Small Steps · Big Results**

A pixel-perfect, fully interactive 21 Days Habit Tracker with live-updating charts, streak calculations, and progress analytics — designed for embedding in Notion.

## Features
- ✅ Interactive 21-day checkbox matrix for 15 habits
- 📊 Live SVG line chart, donut chart, and bar charts
- 🔥 Auto-calculated streaks, progress %, and KPIs
- 💾 Persistent data via localStorage
- 📱 Fully responsive design
- 🎨 Pixel-perfect match to the original Notion template

## Usage
Open `index.html` in any browser, or deploy to GitHub Pages / Netlify / Vercel and embed in Notion via `/embed`.
