How to Use & Embed in Notion

You can bring this exact 21 Days Habit Tracker into your Notion workspace in two powerful ways:

Method 1: Pixel-Perfect Notion Embed (Recommended)

Notion allows embedding full HTML5 web applications directly onto any Notion page with complete interactivity:

  1. Host this file on Vercel, GitHub Pages, or Netlify (1-click free hosting).
  2. In your Notion page, type /embed and hit Enter.
  3. Paste the live link of this habit tracker. It will render exactly as seen here with full interactive checkboxes, live charts, and streak calculations!

Method 2: Native Notion Database (Formulas 2.0)

If you prefer Notion's native database properties:

  • Create a Table Database named 21 Days Habit Tracker.
  • Add 21 Checkbox properties: Day 1, Day 2, ... Day 21.
  • Add a Formula property for Total Completed:
    toNumber(prop("Day 1")) + toNumber(prop("Day 2")) + ... + toNumber(prop("Day 21"))
  • Add a Formula property for Progress % with Notion's native Progress Bar format:
    prop("Total Completed") / 21
